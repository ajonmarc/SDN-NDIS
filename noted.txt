============================================================
SYSTEM FUNCTIONALITY
============================================================

PDRRMO:
- Manage disaster records
- Assign disaster types and municipalities
- Set disaster locations using latitude and longitude
- Publish disaster updates
- Manage evacuation centers
- Upload evacuation center images
- Set center capacity, occupancy and status
- View access logs

GUEST:
- View disaster locations on the map
- Click disaster markers to view disaster details
- View disaster updates
- View evacuation center locations on the map
- Click evacuation center markers to view details and images
- View center addresses, capacity, occupancy and status

MAP REQUIREMENTS:
- DISASTERS.latitude and DISASTERS.longitude determine
  disaster marker positions.
- EVACUATION_CENTERS.latitude and longitude determine
  evacuation center marker positions.
- Use different marker icons or colors for disasters
  and evacuation centers.
- Clicking a marker opens a popup or detail panel.
- The EVACUATION_CENTERS.image column stores an image
  file path or URL, not the actual image file.
- Latitude and longitude may be NULL while locations
  are not yet available; records need valid coordinates
  to appear at a precise map location.

ACCESS LOGGING:
- Record login, logout and guest visits in ACCESS_LOGS.
- user_id references USERS.id when the visitor is logged in.
- user_id is NULL for anonymous visitors.
- Anonymous access logs do not automatically contain
  the visitor's name or full address.
